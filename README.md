# aws-reto
# 👶 App Web - Cuidado y Crianza de Bebés (0 a 2 años)

Este proyecto fue creado con la ayuda de **Amazon Q Developer**, un asistente de desarrollo que permite generar aplicaciones a partir de instrucciones en lenguaje natural.  
En esta ocasión le pedí que construya una **app web informativa para compartir datos sobre el cuidado y la crianza de bebés de 0 a 2 años**.

---

## 🚀 ¿Qué construí?

La aplicación es un sitio web sencillo y accesible que centraliza información clave para madres, padres y cuidadores en la etapa temprana de vida de un bebé.
